# Emil design engineering review — V4

| Before | After | Why |
|---|---|---|
| Hero promise followed by a second long explanation | One sharp promise, one short qualification line and one CTA | The user understands the opportunity before deciding whether to continue. |
| Similar ideas repeated across benefits, profiles and process | Each section now answers one question only | Less cognitive load and a clearer narrative role for every block. |
| Independent numbered sections | Five-stage strip: Scopri, Prova, Scegli, Proponi, Inizia | Turns scrolling into one connected route rather than a collection of modules. |
| Fixed pill navigation persisted over every section | Header remains inside the hero; the journey strip carries orientation | Removes visual interruption and avoids compositing/clipping while scrolling. |
| Hero title and CTA competed for the first viewport | Slightly smaller title with a tighter title-to-card gap | Preserves impact while keeping the primary action visible at 1280 × 720. |
| Support copy sat close to headings and cards | Larger section padding, heading gaps, card padding and ruled transitions | Creates deliberate breath without losing momentum. |
| Product explanation described the trial at length | “Prova Giada. Poi trova il tuo angolo.” plus three short actions | Connects product use directly to the creator’s job-to-be-done. |
| Creator modes used explanatory paragraphs | Short title, one behavioral sentence and one Giada-specific signal | Self-selection remains specific but scans faster. |
| Process copy explained every implication | Four compact rows with explicit commitment labels | The progression is visible before the user reads every word. |
| Application opening used a broad emotional payoff | Direct sequence: contacts, access, brief, idea | Reduces ambiguity and aligns the CTA with the actual next step. |
| Anchor arrival could be partially obscured | Hero-only header and 24 px scroll margin | Every destination opens with its label and headline visible. |
| Mobile layout inherited desktop density | 92 px section rhythm, compact five-step strip and single-column form path | The page stays airy at 390 px without introducing horizontal overflow. |

## Verdict

The page now behaves as one guided narrative: promise, orientation, qualification, product experience, self-selection, process and application. Motion remains restrained, interactions are explicit and the layout keeps Giada’s visual identity while making the copy materially lighter.
