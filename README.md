# Giada Creator Program

Landing page e prototipo del Creator Program / influencer factory di Vivarium per Giada.

## Link

- Production Vercel: https://giada-creator-program.vercel.app
- GitHub: https://github.com/andryza-ctrl/giada-creator-program
- Sites preview: https://giada-creator-program.andrea-zannuto.chatgpt.site

## Sviluppo locale

```bash
npm install
npm run dev
```

## Verifica

```bash
npm run build
npm run test:sites
```

## Deploy

Il repository è collegato a Vercel tramite GitHub:

- ogni push su `main` aggiorna il deploy Production;
- ogni pull request può generare un Preview Deployment;
- `vercel.json` definisce framework Vite, build command e output directory `dist/client`.

## Stato del prodotto

Il form è ancora una demo locale e non invia dati. Copy, compenso, diritti paid, privacy, claim e meccanica definitiva della prova di 7 giorni sono provvisori e richiedono revisione prima del lancio.
