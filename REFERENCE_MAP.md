# Knowledge Studio reference map

Source library: `https://knowledge-studio-andrea.vercel.app`

The library is used as a verified design vocabulary, not as a source of assets to reproduce. Giada's existing type, palette, brand voice, and real product media remain the primary brand system.

| Landing section | Verified reference | Pattern translated into Giada |
|---|---|---|
| Full-page architecture | **Anatomia di una landing page SaaS ad alta conversione** — @uiux.subash | Alternate promise, proof, mechanism, objection removal, repeated CTA, and a clean close. |
| Hero | **Sette hero section moderne come reference UI** — @uiuxmanuel; **10 hero section moderne del mese** — @creative_vaani | One dominant promise, one visual anchor, immediate proof, one primary CTA, and a dedicated mobile hierarchy. |
| Visual art direction | **17 reference visuali per layout, UI e contenuti social** — @Andrea, especially references 09, 13, 15, and 17 | Oversized editorial type; people and UI in one scene; translucent proof cards; constrained palette; product evidence integrated into the composition. |
| Seven-day product trial | Moodboard references 15 and 17 | Show real Giada product screens as an editorial product composition so creators understand what they will experience before proposing an idea. |
| Benefits | **Landing landscaping con hero immersiva e servizi modulari** — @webdesign_786 | Modular benefit cards, outcome-first titles, contextual trust, and repeated conversion cues. |
| Creator profiles | **Landing real estate segmentata per intento** — @webdesign_786 | Three explicit creator paths that help people self-select without turning them into rigid silos. |
| How it works | **Anatomia di una landing page SaaS ad alta conversione** | Explain the mechanism directly after value and fit; use a four-step sequence with the commitment increasing gradually. |
| Selection standards | **Landing landscaping con hero immersiva e servizi modulari**; **Anatomia di una landing page SaaS ad alta conversione** | Place qualification and trust close to the application, framed as clarity rather than exclusion. |

## Motion translation

- Hero entrance is rare marketing motion, using only opacity and transform.
- Frequently used tabs and FAQ controls respond immediately.
- Press states use `scale(0.97)` for 150 ms.
- Hover effects are restricted to fine-pointer devices.
- Reduced-motion removes position movement while preserving useful state feedback.
